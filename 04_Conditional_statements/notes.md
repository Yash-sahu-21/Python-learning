# Conditional Statements in Python

## 1. What are Conditional Statements?
Conditional statements are used to make decisions in a program based on given conditions.

## 2. Types of Conditional Statements

### 1. if Statement
Executes code when a condition is True.

### 2. if-else Statement
Executes one block if the condition is True and another if it is False.

### 3. if-elif-else Statement
Checks multiple conditions one by one.

### 4. Nested if Statement
An if statement inside another if statement.

## 3. Syntax

```python
if condition:
    # Code

elif condition:
    # Code

else:
    # Code
```

## 4. Important Points

- Conditions return `True` or `False`.
- Use a colon (`:`) after each condition.
- Indentation is compulsory in Python.
- `elif` means else if.
- `else` executes when all previous conditions are False.
- Comparison operators are used to check conditions.
- Logical operators can combine multiple conditions.

## 5. Common Operators

| Operator | Meaning |
|---|---|
| `==` | Equal to |
| `!=` | Not equal to |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal |
| `<=` | Less than or equal |
| `and` | Both conditions |
| `or` | At least one condition |
| `not` | Reverses condition |
