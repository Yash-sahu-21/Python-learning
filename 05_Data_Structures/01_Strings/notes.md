# Strings in Python

## 1. What are Strings?
A string is a sequence of characters enclosed in single (`' '`), double (`" "`) or triple quotes (`''' '''`).

```python
name = "Python"
```

## 2. String Operations

- **Concatenation (`+`)** – Joins two strings.
- **Repetition (`*`)** – Repeats a string.
- **Indexing** – Accesses individual characters.
- **Slicing** – Extracts a part of a string.
- **Length (`len()`)** – Returns the number of characters.

## 3. Common String Methods

| Method | Use |
|---|---|
| `upper()` | Converts to uppercase |
| `lower()` | Converts to lowercase |
| `title()` | Converts to title case |
| `capitalize()` | Capitalizes first character |
| `strip()` | Removes extra spaces at ends |
| `replace()` | Replaces text |
| `split()` | Splits a string |
| `find()` | Finds a substring |
| `count()` | Counts occurrences |
| `startswith()` | Checks starting characters |
| `endswith()` | Checks ending characters |

## 4. String Formatting

F-strings are used to insert variables inside strings.

```python
name = "Yash"
print(f"Hello {name}")
```

## 5. Important Points

- Strings are immutable in Python.
- Indexing starts from `0`.
- Negative indexing starts from `-1`.
- Use `len()` to find string length.
- Strings can contain letters, numbers and symbols.
